## 品牌含义

- 「鸣」对应吹奏后发出的声音，也对应第一次真正吹响口琴。
- 「阶」对应音阶、课程阶段和逐步进步。
- 「初鸣」对应新手第一次吹出清晰声音的产品时刻。
- 「见音」对应把原本看不见的音准、稳定度和进步变成可见反馈。

## 图形方向

### A：阶孔

把 10 孔口琴与上升的学习阶段合成一个符号。

- A1：长方孔与三段上升外轮廓。
- A2：圆孔与四段上升外轮廓。
- 当前判断：最接近「鸣阶」的总品牌含义，优先继续。

### B：鸣息

让一条气流穿过第 4 孔并形成声音。

- B1：气流与声线是一条连续路径。
- B2：第 4 孔上方扩散声波。
- 当前判断：B1 能说明产品用途，但需要去掉偏立体的层次；B2 容易被理解为 Wi-Fi，不建议继续。

### C：初鸣

用第 4 孔发出的第一道清晰声音表达首次成功。

- C1：单孔向上形成音高弧。
- C2：单孔形成完整声环。
- 当前判断：C1 容易被理解为伞；C2 容易被理解为定位点或电源符号，均不建议作为总品牌主标。

## 视觉约束

- 主体优先使用简单的线性或径向渐变。
- 非必要不使用高光、阴影笔触。
- 环境光统一影响整个主体，不让零件分别发光。
- 背景使用纯粹渐变或纯色，并保留自适应图标安全区。
- 不使用内发光、内阴影、玻璃、金属或材质噪点。
- 高光保留原色相，不通过混入灰色获得亮度。
- 阴影使用相近色相的深色，不直接混入黑色。
- 图标必须在 32 × 32 像素下保留清楚的口琴与进阶信号。
- 关键图形必须适配圆形、圆角方形、方圆形和水滴形裁切。

## Visual ID 规则板

规则板把用户提供的参考图标与 Kubai Icons React（KIR）拆成可执行的原创规则，不复制参考图轮廓、配色或具体资产。

参考观察：

- 稳定外框：一件主体放进清晰容器，第一眼先看到完整形状。
- 一处切分：用负形或重复几何制造记忆点，不堆叠细节。
- 大片留白：小尺寸仍保留呼吸空间，图形不贴边。
- 颜色克制：一个主色或一处小面积彩色，灰度不作冷蓝味。

鸣阶图形规则：

- 一层底：暖中性底色，纯色或单向渐变；不加弥散光、材质、玻璃。
- 一个主体：低宽 10 孔主体；外轮廓只保留浅阶段节奏。
- 一次负形：一次呼吸切分进入主体，不画脱离主体的气流线。
- 一处浅变化：第 4 孔只用同色相浅变化，不加数字、光圈或描边。

KIR 只贡献层结构与 24 / 28 px 小尺寸验证；不采用它的内发光、内阴影或投影参数。当前只完成规则板，主组件集 `3:44` 与审查框 `3:45` 未修改，Android 启动图标资源也未替换。

2026-11-10 使用 `npm view kubai-icons-react --json` 核验到 `kubai-icons-react` 版本 `0.4.1`，许可证 `MIT`，主页 `https://icons.kubai.design/`，仓库 `https://github.com/kubai087/kubai-icons.git`。该包描述为 React 图标组件，依赖 React `>=18`。本项目是 Flutter 应用，没有把它安装为运行时依赖；这里只把公开视觉方法作为设计参考，不复制具体资产。来源：`npm view` 输出与 <https://icons.kubai.design/>。

当前设计判断：

- `S1` 的口琴识别度最直接，适合作为轮廓基底。
- `S2` 的呼吸切口最像「鸣」，但需要控制切口大小，避免像收纳盒或电池。
- `S3` 的孔距节奏更安静，但阶段感再增强会像琴键或梳齿。
- 推荐下一步以 `S1` 为底，只吸收 `S2` 的一处浅切口，并把 `S3` 的孔距节奏降到最低；这是设计观点，不是已验证的用户选择。
