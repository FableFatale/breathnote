## 1. 背景、定位与商业化策略

### 1.1 核心痛点
十孔布鲁斯口琴入门门槛低，但自学者普遍面临三个障碍：
1. **听不出准不准**：容易吹串孔、音偏高/偏低无法自察。
2. **调号与孔位换算难**：教程大多只写 C 调，用户手里拿着其他调口琴时难以对照。
3. **缺少清晰起步路径**：不知道从最容易吹响的中音第 4 孔起步，练几分钟就因低音闷塞放弃。

### 1.2 产品定位
- **「初鸣」**：把新手第一次吹出清晰单音的瞬间做成最高成就感的体验，从最易发声的第 4 孔（`4↑`）循序渐进。
- **「见音」**：用手机麦克风在本地实时解析音高与气息，让音准、稳定度、十孔健康度和练习进步全部可视化。

### 1.3 商业化与账号策略（已拍板）
鉴于测音、示范音合成、转谱与评分均在端侧运行（零云端边际成本），且十孔口琴本身客单价偏低：
- **核心变现模式**：**免费体验 + 一次性永久买断（Pro 非消耗型内购）**。
- **账号与跨设备策略**：
  - **V1 阶段不做自建邮箱账号与云端同步后端**（暂不引入登录、验证码、云端覆盖/合并冲突、账号注销等重资产模块，大幅降低合规与开发维护成本）。
  - 付费权益直接通过 **App Store / Google Play 原生非消耗型内购 +「恢复购买（Restore Purchases）」** 跨设备恢复。
  - 练习记录与自建曲谱全部本地持久化（后续可提供轻量 JSON 备份导出/导入或系统云备份）。
- **分阶段定价与促销策略**：
  1. **首发冷启动期（前 2～3 个月）**：标示正价锚点（如原价 ¥68 划线），推出 **创世早鸟买断价（如 ¥28 永久买断，含未来全部进阶功能更新）**，配合垂直口琴社区传播与真实多调实测反馈收集。
  2. **功能成熟期（7 课 + 评分诊断 + MIDI 导谱完整上线后）**：买断恢复正价（如 ¥58～¥68），对新用户采用 **爽点触发限时折扣**——用户免费体验完核心起步课程或首次完成曲目评分、点击查看被锁定的「逐音回顾」或「自定义导入」时，触发 **48 小时新手首单立减特惠**；节假日针对未付费老用户做周期性限时促销。
  - *（注：具体定价与试用/折扣幅度为参考值，上线前结合商店定价档位最终确认。）*

### 1.4 免费层 vs 买断 Pro 权益边界

| 功能模块 | 免费版（永久免费） | 一次性买断（Pro 终身版） |
| :--- | :--- | :--- |
| **口琴登记与换调** | 全部 12 调切换 + 吹 4 孔自动识调 + 默认单把口琴 | 额外支持「我的多把口琴」预设清单快速切换 |
| **系统课程（共 7 课）** | **第 01～05 课**（完整掌握口琴结构、呼吸与 `4↑/5↑/4↓` 基础单音） | **解锁第 06～07 课及未来全部进阶课程** |
| **曲谱库** | 开放 2～3 首入门公版曲目（如《小星星》《两只老虎》《欢乐颂》） | 解锁全部内置公版曲目 & 原创练习曲 |
| **跟练与评分** | 逐音跟练模式 + 评分模式总分与 1～3 星级 | 解锁**三维细分评分（音准/节奏/稳定）+ 逐音回顾诊断 + 改进要点建议** |
| **调音器与诊断** | 实时音高表 + 灵敏度调节 + 十孔口琴体检 | 解锁**近 7 天薄弱音位图谱**与历史分布深度分析 |
| **自定义曲谱** | 可预览导谱流程（触发 Pro 解锁提示） | 无限创建/导入（简谱 `1-7` 转谱、口琴文字谱、MIDI/MusicXML、自动移调、压音跳过、同音异孔校对） |

### 1.5 产品范围外（本期不做）
- 半音阶口琴、复音口琴、12 孔口琴；自然小调、乡村等非标准 Richter 调音。
- 压音（Bending）/ 超吹（Overblow）专项评分教学（仅在导谱时做识别标记与跳过）。
- 社交广场、老师人工点评、直播课；**任何存在版权风险的商业流行/动漫歌曲曲谱**。
- 自建邮箱账号系统与多端云端数据库同步（延后至 V2 按需评估）。

## 3. 核心功能规格与验收标准

### F1 首次口琴登记、吹 4 孔自动识调与快捷换调 `🟡 部分实现`
- **默认配置**：未登记或用户选择跳过时，**默认设为 C 调 10 孔口琴**（`✅ 已实现`，`AppController` 默认与重置均已对齐为 `C`）。
- **首次启动登记页（`✅ 已实现`）**：
  - 展示常用 7 调（`C, G, A, D, E, B♭, F`）及「展开其余 5 调」（完整覆盖 12 半音调性 `✅ 已实现`）。
  - 选中任意调号后，页面下方实时预览该调 1–10 孔的上排吹气音名与下排吸气音名（第 4 孔翡翠绿高亮）。
  - **允许跳过**：右上角提供「暂不登记，先体验」（默认 C 调），不强制阻断未拿琴的新用户进入首页；已升级老用户自动免重复弹出。
- **吹 4 孔自动识调（`✅ 已实现`）**：
  - 登记页与调号选择弹窗均提供入口「不确定？吹一下第 4 孔自动识调」。
  - 触发统一麦克风权限流程 → 引导用户自然吹响第 4 孔 → 利用本地 `PitchService` + `detectHarmonicaKeyFromHole4Blow` 提取稳态基频的音级（Pitch Class），稳音锁定后自动选中对应调号并实时更新 10 孔预览。
  - *验收前提：上线前须使用实物口琴对各主调实测校准。*
- **快捷换调与多把口琴**：
  - 「学习」与「曲谱」顶部均提供调号快捷下拉入口（`✅ 已实现`），选择弹窗内支持随时重新进入「吹第 4 孔自动识调」；「我的」页面保留完整调号设置（`✅ 已实现`）。
  - 所选调号全局驱动所有页面的孔位映射、音名、示范音频率与识音目标（`✅ 已实现`）。
  - Pro 用户可保存多把常用口琴预设（如「C 调日常琴」「G 调民谣琴」）并一键切换（`📝 规划中`）。

  - **已替换移除（2 首）**：已彻底移除《天空之城》《千与千寻》，替换为公版名曲 **《奇异恩典（Amazing Grace）》** 与初鸣原创练习曲 **《初鸣微风（First Breeze）》**；曲库后 5 首与自建曲谱归入 Pro 买断。

  - 新增草图中的 **分类筛选标签（`全部 / 入门 / 已完成 / 收藏`）**、**收藏开关**与 **曲目最高星级（1–3 星 / 最高分 / 未练习）** 展示（`✅ 已实现`）。

#### 3.2 曲谱练习双模式
在曲谱练习页（`SongPracticeScreen`）提供顶部轻量模式切换，兼顾认孔新手与进阶打分需求：
1. **跟练模式（默认，`✅ 已实现`）**：
   - 卡点等待推进：不催促节奏，吹准当前高亮孔位即自动推进至下一个音。
   - 支持示范音播放、`0.5× / 1×` 变速、循环播放与 Palermo 蓝（吹 `↑`）/ 橙（吸 `↓`）视觉区分。
2. **评分模式（跟吹评分，`✅ 已实现`）**：
   - 预备拍倒数后按设定速度（`0.5× / 1×`）沿音高时间线推进，实时显示当前得分、连续命中数与实时音分偏移。
   - 吹完进入 **评分结果页**：
     - **所有人可见**：总分（0–100）、星级（1–3 星）、成就分享卡片按钮（复用现有分享卡组件）、再练一次 / 下一课。
     - **Pro 买断解锁**（免费用户展示锁定引导与新手限时折扣入口）：
       - **三维细分评分**：音准分 / 节奏分 / 稳定度分（权重与 `±25¢` 准音阈值须经实体口琴实测校准）。
       - **逐音回顾条**：逐个音符标明 `准 / 偏低 / 偏高 / 漏吹`，点击可复听该音示范音。
       - **针对性要点建议**：根据本次失误最多的孔位自动生成 1 句人话改进提示（例：「6 吸整体偏低，吸气时放松喉咙、气流再集中一点」）。
- **已知声学限制**：十孔口琴 `2 孔吸` 与 `3 孔吹` 音高完全相同，端侧测音仅判定音高是否准确，不区分物理孔位，在说明与评语中予以包容。

### F4 自定义曲谱 3 步式工作流 `🟡 部分实现`
将现有的自建曲谱弹窗升级为统一、专业、对国内与海外用户都友好的 **3 步导谱流程**（创建/导入归入 Pro 买断，所有自建曲谱仅存本机不公开分享）：

1. **Step 1 选择曲谱来源**：
   - **文字输入（`✅ 已实现`）**：支持直接输入口琴谱记法（如 `4↑ 4↑ 6↑ 6↑`）以及 **简谱 `1–7` 自动转口琴谱**（`convertJianpuToTabs`）。
   - **文件导入（`📝 规划中`，P1）**：支持导入本地 **MIDI / MusicXML** 文件，提取主旋律音高与基本时值。
   - **拍照 / PDF 识谱（`📝 远期 V2`）**：仅作为未来实验室方向，不纳入首期交付承诺。
2. **Step 2 自动移调与压音预览（`📝 规划中`）**：
   - 自动将原曲移调至「当前登记口琴下需压音最少」的最优调，展示如 `原调 C 大调 → 当前 C 调口琴（移调 0 半音），29 个音可直接吹，3 个需压音`。
   - 支持用户手动 `− / +` 按半音微调移调结果，实时刷新孔位与压音计数。
   - 绿色边框标示可直接吹奏的音，琥珀色边框标示需压音的音；提供开关 **「评分时跳过需要压音的音」**。
3. **Step 3 同音异孔校对（`📝 规划中`，可一键跳过保存）**：
   - 当某音符存在多个同音孔位可选（典型如 `2 孔吸` vs `3 孔吹`）时，系统默认推荐「距离前一个音手部移动最少」的孔位，并允许用户点选切换后保存至曲谱库（同时支持选择 8 种封面图标 `✅ 已实现`）。

### F5 调音器、十孔体检与数据分析 `✅ 已实现`
以当前功能完善的调音页为骨架，融合草图直观元素：
- **实时音高仪表盘（`✅ 已实现`）**：圆弧音分偏差指针、三档语义反馈（`±10¢` 翡翠绿锁定、`10¢–25¢` 琥珀黄临近、`>25¢` 红色偏差）、当前音名与频率。
- **1–10 孔横向实时高亮条（`✅ 已实现`）**：在仪表盘下方紧凑呈现 1–10 孔横向口琴条，实时高亮当前吹（蓝 `↑`）/ 吸（橙 `↓`）命中的孔位与音名，并支持 `2↓ / 3↑` 同音同步点亮。
- **麦克风灵敏度调节（`✅ 已实现`）**：无 `GlobalKey` 滑块（`0.0–1.0`，默认 `0.68`），拖动即时生效、松手持久化并与所有练习页共享。
- **十孔口琴体检（`✅ 已实现`）**：逐孔吹/吸检测 1–10 孔发音状态，帮助排查新琴哑音或漏气，支持一键重置。
- **练习数据诊断（`✅ 已实现`）**：
  - 本次音准点阵分布图（Session Distribution）。
  - 近 7 天薄弱音位图谱（Weak Note Map，基于近 400 条本地 `PitchAttempt` 按 20 个动作统计 `≤25¢` 命中率；成熟期可纳入 Pro 进阶分析）。

## 4. 非功能需求、合规与风险

### 4.1 性能与无障碍
- **音频延迟**：实时测音与音高指针刷新需经真机实测并保持顺滑无卡顿；界面明确提示蓝牙耳机延迟问题，推荐使用有线耳机或外放适度音量。
- **无障碍规范**：可点击控件最小触控热区不小于 `44×44` dp/pt；支持系统动态字体放大不截断；除颜色区分（蓝吹/橙吸/绿准/红偏）外，必须同时提供文字或图标/箭头标注（如 `↑` / `↓`、`准 / 偏低 / 偏高`）。

### 4.2 本地埋点与关键观测指标（可选，严格遵守匿名最小化）
若上架后接入轻量匿名统计，核心关注以下指标以验证冷启动与买断转化：
- 首次打开 → 口琴登记完成率（含「吹 4 孔识调」使用率与跳过率）
- 麦克风授权通过率
- 首次完成第 3 课（`4↑` 初鸣）转化率 & 首次完成曲目评分完成率
- 次日 / 7 日本地留存率
- Pro 买断页曝光 → 支付成功转化率（区分首发早鸟价 vs 48h 新手折扣转化）

### 4.3 合规与风险控制清单

| 风险项 | 风险说明 | 应对措施 |
| :--- | :--- | :--- |
| **曲谱版权风险** | 商业流行/动漫配乐（如现网代码里的《天空之城》《千与千寻》）上架应用商店易触发侵权下架 | **上架前强制替换为公版传统曲目与原创练习曲**；用户自建/导入曲谱仅存本机、禁止公开分享 |
| **第三方商标避嫌** | 口琴品牌名（如 Fender、Hohner、Blues Deluxe 等）不可出现在图标、界面、商店副标题及关键词中 | 全站统一使用「十孔布鲁斯口琴 / 十孔口琴」通用称谓 |
| **应用商店内购审核** | 非消耗型买断必须提供明显可用的「恢复购买」入口，禁止诱导性/误导性限时倒计时造假 | 买断页规范展示权益、一次性收费说明、恢复购买与隐私协议；限时折扣须真实按设备首次安装时间计算 |
| **物理声学与多调校准** | `2 孔吸 = 3 孔吹` 同音不可物理区分；除 C/F 外的其余 10 个调由半音偏移推算 | 评分算法宽容同音异孔；上线前使用实体 C/F/G/A 等常用调口琴逐调核对测音阈值 |
